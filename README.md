# Barbershop — Booking App

> Interactive web app prototype for modern barbershops, featuring a haircut catalog and appointment scheduling.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Barbershop & men's grooming

Interactive web app prototype for modern barbershops, featuring a haircut catalog and appointment scheduling.

**Highlights**

- Service catalogue with pricing and duration
- Booking by barber and available time slot
- Subscription plans and loyalty rewards

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
